# 🎁 Вишлист Софьи и Артура

Общий вишлист на двоих. Экран поделён на **две половины** — слева Софья, справа Артур.
У каждого внизу — **свой список желаний** и форма добавления.

На каждое желание можно указать:

- название подарка,
- **ссылку на товар**,
- **ссылку на картинку**.

Клик по картинке (или кнопке «Открыть») переводит на страницу товара.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | сайт-вишлист (две половины экрана) |
| `style.css` | оформление |
| `script.js` | логика сайта (добавление, удаление, сохранение) |
| `bot.py` | Telegram-бот на aiogram — присылает кнопку «Открыть вишлист» |
| `requirements.txt` | зависимость бота (`aiogram`) |

## Как это работает

- **Сайт** — статический, живёт на GitHub Pages:
  **https://arturklimcue-svg.github.io/Wishlist1/**
- **Бот** запущен на [Bothost](https://bothost.ru): [@WishlistKlimchukibot](https://t.me/WishlistKlimchukibot)
- При запуске бот присылает кнопку «Открыть вишлист» — по нажатию открывается сайт
  (внутри Telegram или в браузере).

Данные вишлиста хранятся в браузере устройства (`localStorage`) — на каждом
устройстве свой список.

## Деплой бота на Bothost

1. Зарегистрируйтесь на [bothost.ru](https://bothost.ru).
2. Создайте бота:
   - **Платформа**: Telegram
   - **Библиотека**: Python (aiogram)
   - **Bot Token**: токен от @BotFather
   - **Git URL**: `https://github.com/arturklimcue-svg/Wishlist1`
   - **Ветка**: `main`
   - **Главный файл**: `bot.py` (определится автоматически)
3. Нажмите «Создать» — Bothost установит зависимости из `requirements.txt`
   и запустит бота.
4. Напишите боту `/start` — придёт кнопка «Открыть вишлист».

Токен на Bothost подставляется автоматически в переменную `BOT_TOKEN`.
Если нужно открывать другой адрес — задайте переменную окружения `SITE_URL`.

## Локальный запуск

Сайт:

```bash
python3 -m http.server 8080
```

Бот:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
BOT_TOKEN=<токен> python bot.py
```

## Безопасность

- В репозитории **нет токенов** — всё через переменные окружения.
- Если токены где-то пересылались в открытом виде — лучше перевыпустить их
  (GitHub: Settings → Developer settings → Tokens; Telegram: @BotFather → /revoke).
